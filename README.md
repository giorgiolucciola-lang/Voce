# Voce

App web personale per l'allenamento vocale quotidiano.

Un semplice tool HTML, autonomo e utilizzabile offline, pensato per una breve routine giornaliera di esercizi vocali: respirazione, risonanza e articolazione.

## Cosa fa

Ogni sessione propone:

- **Un momento di respirazione iniziale**, per prepararsi prima degli esercizi veri e propri
- **Esercizi di respirazione diaframmatica**
- **Esercizi di risonanza** (es. "mmm" a labbra chiuse, sbadiglio-sospiro)
- **Esercizi di articolazione** (sequenze consonantiche, scioglilingua)

Ogni esercizio indica la durata consigliata e può essere segnato come completato. È presente un contatore dei "giorni di fila" per tenere traccia della costanza.

## Come si usa

Apri il file `.html` direttamente nel browser (doppio clic dal Finder). Non richiede installazione né connessione internet per le funzionalità base.
